# 캠핑 노트

캠핑 장부와 캠핑장 기록을 한 애드온에서 실행합니다. 설치·데이터 이전·개발 위치는 [통합 안내](INTEGRATION.md)를 참고하세요.

# CAMP LEDGER · 캠핑용품 장부

Home Assistant에서 사용하는 캠핑용품 구매·판매·폐기 장부입니다.

## 설치

1. **설정 → 앱(이전 명칭: 애드온) → 앱 스토어 → ⋮ → 저장소**에 `https://github.com/kojungho/camp-ledger-addon`를 추가합니다.
2. **캠핑용품 장부**를 설치하고 시작합니다.
3. **사이드바에 표시**를 켜고 **웹 UI 열기**를 누릅니다.

Home Assistant OS 또는 Supervisor가 있는 환경이 필요합니다. Intel/AMD(amd64), ARM64(aarch64) 사전 빌드 이미지를 GitHub Container Registry에서 내려받습니다. 별도 포트 개방이나 추가 계정은 필요하지 않습니다.

## 예약 플랫폼 수동 동기화

Android **캠핑 노트 1.0.14 이상**에서 캠핑장 기록 상단의 **예약 동기화**를 누르고 캠핏·땡큐캠핑·캠핑톡을 선택합니다. 플랫폼에 직접 로그인하고 예약 목록 또는 상세 화면을 연 뒤 **현재 예약 동기화**를 누르세요. 내용을 기존 등록 폼에서 확인·수정하고 **동기화 반영**을 누르면 저장됩니다. 로그인하거나 앱을 여는 것만으로 기록이 변경되지는 않습니다.

현재 화면에 불러온 예약을 한 번에 최대 20건 읽습니다. 이전 내역은 목록을 스크롤하거나 다음 페이지를 열고 다시 동기화합니다. 화면에서 예약별로 구분되는 대표 사진 1장·배치도 3장까지 선택해 가져올 수 있습니다. 배치도는 사진 설명 등에서 배치도로 확인되는 경우만 가져오며, 다른 상세 페이지를 자동으로 찾아가지는 않습니다. 사진을 가져오지 못해도 예약 정보는 검토할 수 있습니다.

플랫폼별로 저장을 완료한 예약 번호·캠핑장명·입실일·퇴실일의 이력을 보관해 다음에는 새 예약만 보여줍니다. 기존 기록은 덮어쓰지 않으며, 확인창에서 취소하거나 저장에 실패한 예약은 완료로 처리하지 않습니다. 다른 기기에서도 같은 이력을 사용합니다. 동기화로 저장한 뒤 기록을 삭제해도 같은 예약을 자동으로 다시 등록하지 않습니다. 이미 반영한 것으로 확인되는 예약의 사진은 앱에서 다시 내려받지 않습니다. 예약을 구별하려면 현재 페이지의 글자를 확인해야 하며, 플랫폼에 새로운 내역만 요청하는 공식 API 방식은 아닙니다. 취소 완료로 표시된 예약은 건너뜁니다. 반영 전 변경될 내용을 확인해주세요.

로그인은 앱의 별도 플랫폼 화면에서 처리하며 비밀번호·로그인 쿠키를 홈어시스턴트에 전송하지 않습니다. 공식 예약 연동 API가 아닌 현재 페이지 읽기 방식이므로 플랫폼 화면 변경, 소셜 로그인 및 인앱 브라우저 제한에 따라 동작이 달라질 수 있습니다. 실제 계정 로그인·내역 호환성은 휴대전화에서 확인해야 합니다. 로그인 제한을 우회하지 않으며, 지원되지 않는 경우 기존 예약 사진·문자 입력을 이용합니다. 아이폰·일반 웹에서는 현재 예약 사진·문자 입력을 사용합니다.

## 기능

- 첫 화면 기본: 구분, 상품명, 구입가격, 판매가격. 설정에서 모든 상품 필드·사진의 표시 여부와 금액 요약 카드를 선택 가능. 표시하지 않은 항목도 상세·엑셀에는 유지.
- 상품 클릭: 상세 팝업에서 구입일, 구입처, 구매자, 상태, 판매·폐기 날짜, 메모 조회·수정
- 상품명 옆 대표 상품 사진 표시
- 영수증·상품 사진 별도 분류: 여러 장 첨부, 삭제, 확대, 원본 내려받기. 개수 제한 없이 저장 공간 범위 내 사용
- 수량: 구매수량·현재수량·판매수량 입력. 나머지는 폐기·소진수량. 부분 판매·폐기 품목은 해당 탭에 함께 표시.
- 원가: 누적 구입금액 ÷ 누적 구매수량으로 평균 단가 계산. 현재금액 = 평균단가 × 현재수량(원 단위 반올림). 차감금액 = 누적 구입금액 − 현재금액.
- 추가 구매: 품목 상세의 추가 구매에서 수량·금액·일자·구매유형(새상품/중고/미기재)을 기록. 현재수량도 함께 증가하고 누적 평균 단가 갱신.
- 공동구매: 개별 원가를 모르면 미확정으로 표시. 공동구매 금액은 한 품목에만 구입가격으로 계상하여 중복 합산을 피함. 미확정 품목의 평균단가·현재금액·차감금액은 계산하지 않으며 현재 보유금액 합계는 확정분만 표시.
- 변경 이력: 등록, 필드 수정, 사진 추가·삭제 시각과 내용 자동 기록
- 전체 / 보유 / 판매 / 폐기 탭, 검색·분류·정렬, 개별·선택 삭제
- 전체 구입금액, 판매 완료 상품의 회수금액, 순지출, 보유 상품 구입금액 집계
- 엑셀 업로드: 양식 다운로드 → 작성 → 파일 선택 → 내용 확인 → 추가. 기존 상품·사진·이력은 유지하고 새 상품으로 추가. 오류가 있으면 전체 반영하지 않음. 같은 파일을 새로 업로드하면 상품도 다시 추가됨. 새 분류값은 목록에 자동 추가. .xlsx, 20MB·20,000개 상품까지. 사진은 업로드 후 상세 화면에서 첨부.
- 엑셀: 필터와 무관하게 전체 상품·변경 이력·첨부 사진(미리보기)·설정·금액 집계·구매 내역를 6개 시트로 저장
- 모바일에서도 상단 **⚙ 설정**으로 장부 설정 열기
- 설정: 구분·구입처·구매자 목록 추가·삭제, 항목별 글자 크기·열 너비, 행·제목 행 높이·셀 여백, 제목·상세 글자 크기
- 전체 백업·복원: 모든 상품, 이력, 설정, 사진 원본을 ZIP으로 저장

금액은 원화 정수이며, `판매가격`을 입력한 보유 상품은 실제 판매 회수금액에 포함하지 않습니다. 상태를 **판매 완료**로 바꾸면 합산합니다. 순지출은 전체 구입금액에서 판매 완료 금액을 뺀 값이며 보유 자산의 현재 시세는 아닙니다.

사진 지원 형식: JPG, PNG, WebP, GIF. 엑셀에는 사진 미리보기가 들어가고 원본은 전체 백업 ZIP에 보관됩니다. 사진을 많이 등록할 때는 HA 저장 공간을 확인해주세요. 삭제는 사진과 이력도 함께 지우므로 필요하면 먼저 백업하세요. 목록에서 분류값을 삭제해도 기존 상품의 값은 유지됩니다.

데이터는 애드온의 `/data/camp-ledger/ledger.sqlite3`에 저장됩니다. 브라우저·기기를 바꿔도 같은 장부가 열리고, 재시작·업데이트 후에도 유지됩니다. Home Assistant 애드온 백업 대상에 포함되며 웹 UI에서도 별도 백업이 가능합니다.

## 이미지 배포

GitHub Actions가 테스트 후 amd64와 aarch64 이미지를 빌드하고 `ghcr.io/kojungho/camp-ledger:<버전>` 다중 아키텍처 이미지로 배포합니다. 업데이트할 때 `camp_ledger/config.yaml`의 버전을 올리고 main으로 push하세요. 성공한 빌드가 끝난 후 HA 스토어에서 업데이트 확인을 실행합니다. GHCR 패키지의 공개 범위는 **Public**이어야 HA가 로그인 없이 설치할 수 있습니다.

## 개발 실행

```sh
python3 -m venv .venv
.venv/bin/pip install -r camp_ledger/requirements.txt
CAMP_DATA=./data CAMP_HOST=127.0.0.1 .venv/bin/python camp_ledger/app.py
```

`http://127.0.0.1:8099`에서 확인할 수 있습니다. 기본 데이터는 빈 목록으로 시작합니다. 애드온에서는 Home Assistant Ingress를 통해 인증하고 일반 네트워크 포트를 공개하지 않습니다.

## 앱 설치와 외부 접속

장부 설정의 **앱 설치·연결**에서 안드로이드 설치 파일(APK)을 내려받습니다. Android 10 이상을 지원합니다. 아이폰은 외부 앱 주소를 Safari로 열고 **공유 → 홈 화면에 추가**로 설치합니다. Safari 17.2 이상에서는 연결 쿠키가 홈 화면 앱에도 전달됩니다.

외부 연결은 기본적으로 꺼져 있습니다. 계정의 로그인 화면 대신 기기 전용 연결키를 사용하며, 처음 한 번 기기를 연결하면 자동 접속합니다. 안드로이드는 기기 보안 저장소로 키를 암호화하고 앱 백업을 허용하지 않습니다. 웹앱은 Secure·HttpOnly 쿠키를 사용합니다. HA 안의 설정에서 각 기기를 해제할 수 있습니다. 외부 기기는 장부 데이터만 읽고 수정하며 기기 연결 관리·외부 연결 설정에는 접근할 수 없습니다.

별도 인터넷 포트를 열지 않고 기존 HA HTTPS 주소의 **/camp-ledger/** 경로를 이용할 수 있습니다. 제공되는 연결 구성요소를 `/config/custom_components/camp_ledger_bridge`에 설치하고, `configuration.yaml`에 아래를 추가한 뒤 설정 검사와 HA 재시작을 진행합니다.

```yaml
camp_ledger_bridge:
```

연결 구성요소는 장부 앱의 비공개 내부 포트 8098로만 전달하며, HA의 다른 API나 로그인 정보는 전달하지 않습니다. 장부 설정에서 외부 주소를 `https://ha.badara.co.kr/camp-ledger/`로 입력하고 외부 앱 연결을 허용합니다. 그다음 기기 이름과 설치 방식을 선택해 연결 버튼 또는 QR을 만듭니다. 연결키를 가진 기기는 장부 조회·수정·삭제·파일 내보내기가 가능합니다. 연결키는 공유하지 마세요.

공개 GitHub의 APK에는 사용자의 장부 데이터나 연결키가 들어있지 않습니다. APK 서명키는 소스 저장소에 포함하지 않습니다. 서명키를 바꾸면 기존 앱을 제거한 뒤 새 APK를 설치해야 하므로, 업데이트 시 기존 키를 유지하세요. 설치 파일의 빌드 및 서명은 Android SDK의 `aapt2`, `d8`, `apksigner`로 검증합니다.
