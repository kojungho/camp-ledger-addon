# 플랫폼 화면 시작 검사

테스트용 Android 가상 기기에 캠핑 노트 APK를 먼저 설치합니다. 실제 예약 계정이나 HA 연결키 없이 세 플랫폼 화면을 각각 두 번 열어 WebView 초기화와 닫기를 검사합니다. 테스트 전용 APK는 배포 APK와 같은 키로 서명해야 합니다.

`ANDROID_SDK_ROOT`, `JAVA_HOME`, `CAMP_ANDROID_TEST_DIR`(저장소 밖 임시 경로), `CAMP_ANDROID_TEST_SERIAL`(테스트 가상 기기), `CAMP_APK_KEYSTORE`, `CAMP_APK_STOREPASS`를 설정하고 `bash android/camp-note/tests/run-startup-test.sh`를 실행합니다. 암호는 로그나 소스에 기록하지 않습니다. 스크립트는 선택한 가상 기기에 테스트 APK를 설치하며 기존 앱 데이터를 지우지 않습니다.

결과에 `result=PASS`가 있어야 성공입니다. 기존 1.0.13은 `PlatformActivity.onCreate → PhoneWindow.getInsetsController`의 NullPointerException으로 종료되었고, 1.0.14에서 같은 검사 6회가 통과했습니다. 플랫폼 실제 계정 로그인·예약 수집 검사와는 별도입니다.

1.0.15 검사는 네이버를 포함한 네 플랫폼 화면 시작, 실제 WebView의 로컬 예약 목록 자동 스크롤·추가 로드·취소 상태 인식, 두 계정 프로세스의 쿠키 격리와 재실행 후 유지 검사를 포함합니다. 테스트 HTML과 테스트 쿠키만 사용하며 실제 계정에 로그인하지 않습니다.

1.0.16은 이전에 동기화한 예약 번호를 중단 기준으로 전달하고, 실제 WebView에서 그 앞의 새 예약만 반환하는 검사도 포함합니다. 목록은 최신 예약이 위에 있는 상태를 기준으로 하며 다음 페이지·다른 탭으로 자동 이동하지 않습니다.
캠핏 상세 화면의 연도 없는 입실·퇴실 날짜와 취소 상태를 실제 WebView의 로컬 상세 화면으로 검사합니다. 예약자·계좌 정보가 결과에 포함되지 않는지도 확인합니다.

1.0.17은 네이버 상세 팝업에서 동기화 버튼이 보이고 뒤쪽 화면 대신 열린 상세 예약을 읽는 검사를 포함합니다. 네이버 숙박/최근 목록의 장소·상품·날짜·숙박 마크 구분은 제공된 화면을 본뜬 로컬 자료로 검사합니다. 실제 플랫폼 계정의 화면 구조까지 확인한 것은 아닙니다.

1.0.18은 네 플랫폼 각각의 실제 WebView에서 접힌 details·제어된 예약 정보 영역을 펼쳐 사이트·주소·금액과 캠핑장/지도 공개 링크를 수집하는 검사를 포함합니다. 플랫폼을 본뜬 로컬 HTML을 사용하며 실제 계정 예약 내역 검사를 대신하지 않습니다.

1.0.19은 네이버 메인 혼합 목록에서 예약 내부 글자와 바깥 가격·사진·루트 링크를 한 건으로 묶고, 실제 예약 상세 링크의 추적·인증 매개변수를 제거하는 검사를 추가합니다. 사진 주소 검출과 안전하지 않은 로컬 사진 주소 거부를 검사하며, 실제 네이버 계정/CDN 다운로드 성공을 대신하지 않습니다.

`ThemeTest`는 `themeScript` 인자에 공통 `theme.js`의 Base64 문자열을 전달하여 별도로 실행합니다. 네트워크나 연결키 없이 로컬 WebView에서 기기 야간 모드, 명시적 라이트 우선, 자동 모드 복귀 및 설정 변경 즉시 적용을 확인합니다.
