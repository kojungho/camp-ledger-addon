앱 설치 방법

안드로이드

  1. 아래 설치 파일을 다운로드합니다.
  2. 파일 앱에서 APK를 열고 설치합니다. 요청되면 이 출처의 앱 설치를 허용합니다.
  3. 아래 ‘이 휴대폰 연결’을 누르면 앱이 열리면서 자동으로 연결됩니다. PC에서는 ‘새 기기 연결’을 누른 뒤 휴대폰으로 QR을 읽으세요.
  4. 설정에서 갤러리 또는 파일 앱을 선택합니다.
캠핑 노트 설치 파일 다운로드 (camp-note.apk)

아이폰 / 아이패드

  1. 아래 ‘이 기기 연결’을 누르거나 PC에 표시된 QR을 읽습니다.
  2. 연결 주소를 Safari로 열어 연결합니다.
  3. 공유 → 홈 화면에 추가 → 웹앱으로 열기 → 추가를 누릅니다.
  4. 홈 화면의 ‘캠핑 노트’ 아이콘으로 바로 접속합니다.

아이폰용은 홈 화면 웹앱입니다. App Store 배포 앱은 아닙니다. iOS 17.2 이상을 권장합니다.

캠핑장 기록 · 캠핑 장부 통합 화면

새 안드로이드 앱은 위쪽 전환 버튼으로 두 화면을 함께 사용합니다. 아이폰은 통합 화면을 Safari에서 연 뒤 홈 화면에 추가하세요. 연결키 하나로 캠핑장 기록과 캠핑 장부를 모두 사용합니다. 기존 기기 연결도 유지됩니다.

이 기기는 이미 연결되어 있습니다. 새 기기 연결과 해제는 홈어시스턴트에서 관리합니다.
