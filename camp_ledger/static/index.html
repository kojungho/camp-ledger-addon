앱 설치 · 연결

처음 한 번 연결하면 로그인 화면 없이 자동 접속합니다.

안드로이드 · 설치부터 연결까지

  1. 설치 파일 다운로드휴대폰에서 아래 ‘안드로이드 앱 설치 파일’을 누르세요.
  2. 앱 설치다운로드한 APK를 열고 설치하세요. 설치가 막히면 해당 브라우저의 ‘이 출처 허용’을 켜세요.
  3. 외부 연결 준비HA 장부 설정에서 외부 앱 주소를 확인하고 ‘외부 앱 연결 허용’을 켠 뒤 ‘연결 설정 저장’을 누르세요.
  4. 기기 연결 만들기기기 이름을 입력하고 ‘안드로이드 앱’을 선택한 뒤 ‘기기 연결 만들기’를 누르세요. 이미 연결된 기기는 다시 만들 필요가 없어요.
  5. 앱과 연결설치한 휴대폰에서 ‘안드로이드 앱 연결’을 누르세요. 열리지 않으면 연결키를 복사해 앱 첫 화면에 붙여넣고 ‘장부 연결’을 누르세요. PC에서 만들었다면 휴대폰으로 QR을 읽으세요.
  6. 장부 바로 열기이후에는 설치한 ‘캠핑 장부’ 앱을 열면 로그인 없이 장부가 표시돼요. 인터넷이 연결되어 있으면 외부에서도 사용할 수 있어요.
아이폰 · 홈 화면 앱 설치 순서
  1. HA 장부 설정에서 외부 연결을 켜고 저장하세요.
  2. 기기 이름을 입력하고 ‘아이폰 / 홈 화면 앱’을 선택해 ‘기기 연결 만들기’를 누르세요.
  3. 아이폰 Safari에서 ‘홈 화면 앱 열기’를 누르거나 QR을 읽어 장부를 여세요.
  4. 장부의 ‘홈 화면에 앱 설치’를 누르고, Safari 공유 메뉴 → ‘홈 화면에 추가’를 선택하세요.
  5. 홈 화면의 ‘캠핑 장부’를 열어 사용하세요.

외부 연결 설정과 연결키 만들기는 HA에서 연 장부 설정에 표시됩니다. 연결키는 다른 사람에게 공유하지 마세요.

연결 버튼이 열리지 않으면 앱 첫 화면에 위 연결키를 붙여넣으세요. 설치 후 이 휴대폰에서 연결 버튼을 누르거나 QR을 읽어주세요. 연결 정보는 이 장부에 접근할 수 있는 기기 전용키입니다.
